# Vishnu Varthan Prakash — Portfolio

A production-grade React portfolio with 3D animated background, Job Tracker, dark mode, and full responsiveness.

## 🚀 Tech Stack
- React 18
- Framer-like CSS animations (no extra deps)
- Canvas API for 3D particle animation
- localStorage for Job Tracker persistence

## 🛠️ Local Development

### Step 1 — Install Node.js
Download from: https://nodejs.org (LTS version)

### Step 2 — Install dependencies
```bash
cd portfolio
npm install
```

### Step 3 — Start dev server
```bash
npm start
```
Opens at: http://localhost:3000

## 🐙 Push to GitHub

### Step 1 — Create GitHub account
Go to https://github.com and sign up (if you don't have one)

### Step 2 — Create a new repository
1. Click the **+** button → "New repository"
2. Name it: `portfolio`
3. Set it to **Public**
4. **Don't** initialize with README (we have one)
5. Click "Create repository"

### Step 3 — Initialize Git and push
Open terminal in your portfolio folder and run:

```bash
git init
git add .
git commit -m "🚀 Initial portfolio commit"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/portfolio.git
git push -u origin main
```

> Replace `YOUR_USERNAME` with your GitHub username

## ▲ Deploy on Vercel

### Option A — Via Vercel Dashboard (Recommended)
1. Go to https://vercel.com and sign up with GitHub
2. Click **"Add New Project"**
3. Import your `portfolio` GitHub repository
4. Vercel auto-detects React — leave all settings as default
5. Click **"Deploy"**
6. Your site is live at: `https://portfolio-YOUR_USERNAME.vercel.app`

### Option B — Via Vercel CLI
```bash
npm install -g vercel
vercel login
vercel
```

## 🔧 Customization

### Update LinkedIn / GitHub links
Open `src/App.js` and find the Contact section:
```js
href="https://linkedin.com"   // Replace with your LinkedIn URL
href="https://github.com"     // Replace with your GitHub URL
```

### Update Resume
Replace `public/Resume.pdf` with your latest resume PDF.

### Update Photo
Replace `public/photo.png` with your photo (keep same filename).
